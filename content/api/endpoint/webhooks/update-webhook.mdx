Update a webhook. Only the fields provided are changed - a field sent as `null` is cleared, and fields left out are unchanged. `PUT` is also accepted, with the same behaviour. `stream` and `label` accept a stream/label ID or name, and are only applied when the webhook's event uses them. The update is rejected if it would duplicate another webhook. Requires `webhooks:write` scope.
