Get the status of an upload - in particular, to follow a build through processing after `/upload/verify` returns `pending_processing: true`. `percentage_processed` shows progress; if it stops changing for longer than `stall_timeout_seconds`, processing has most likely failed. Uploads not verified within 48 hours, and processing that doesn't finish, are reported as `failed`. Requires `builds:read` scope.
