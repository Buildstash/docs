Share up to 10 releases with a distribution group, optionally emailing its testers. When emailing, each tester gets one email per application: several releases of the same application are covered by a single email linking to the newest, and testers aren't emailed again about releases they've already been notified of. Requires `distribution_groups:write` scope. Only available with workspace API keys.
