List an application's builds published on a portal - all its builds, or those in streams published on the portal, depending on the portal's settings. Returns no builds if the portal doesn't publish builds for the application. The application must be linked to the portal (`404` otherwise). Requires `portals:read` and `builds:read` scopes. Only available with workspace API keys.
