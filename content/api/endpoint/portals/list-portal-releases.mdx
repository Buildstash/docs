List an application's releases published on a portal - all its releases, or only those published to the portal, depending on the portal's settings. Returns no releases if the portal doesn't publish releases for the application. The application must be linked to the portal (`404` otherwise). Requires `portals:read` and `releases:read` scopes. Only available with workspace API keys.
